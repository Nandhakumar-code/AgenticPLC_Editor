# AgenticPLC
NextGEN PLC Software

## Project Objective
Building My Own PLC software and ESP32 Based Customized PLC Hardware

Integrating AI Agent Into the PLC software so the users Do not need to know or write st code and draw ladder diagram Manually.

Digital Twin for visual understanding before moving for hardware

Error Debugging

## Tech Stack
### Frontend
- HTML
- CSS
- React framework
- Monaco editor for ladder canvas
- Electron desktop

### Backend
- Node.js

### File Storage
- Local file system
- No security issues

## AI Providers + AI Content Access Protocols Used
### AI Providers
- Around 79 LLM models
- Optimized for 100% free usage with fallback LLM service provider
- Auto fallback when one LLM provider free tier exceeds its limit

### AI Content Access Protocols
- Multi-provider LLM orchestration
- Free-tier aware provider switching
- Automated fallback handling for AI service availability

## Project Summary
AgenticPLC is a next-generation PLC software platform designed to simplify industrial automation by combining custom PLC development, AI-assisted logic generation, digital twin simulation, and debugging. The goal is to let users build PLC logic without manually writing ST code or drawing ladder diagrams, while validating behavior virtually before hardware deployment.
